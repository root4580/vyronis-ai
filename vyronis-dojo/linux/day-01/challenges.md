# Day 1 Linux — Quick reference card

Print or keep open while training.

```bash
pwd                 # where am I?
ls                  # list
ls -la              # list all details
cd path/to/dir      # enter directory
cd ..               # go up
cd ~                # go home
cat file.txt        # show file contents
echo "text"         # print text
echo "text" >> f    # append text to file
touch newfile       # create empty file
```
