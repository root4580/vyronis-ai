# 30-Day Map — 2 Programming + Linux Daily

Each day = **2 programming micro-skills** (2h) + **Linux** (1h).  
Weekends still count — rest day only if *you* choose Sunday off.

## Week 1 — White Belt: "I speak computer"

| Day | Programming skills | Linux skills |
|-----|-------------------|--------------|
| 1 | Instructions & `console.log` · Variables & types | Terminal exists · `pwd` `ls` `cd` |
| 2 | Strings & template literals · `if` / `else` | Paths · `mkdir` `touch` `cat` |
| 3 | Numbers & operators · Comparison `===` | `head` `tail` `wc` · flags |
| 4 | Functions (declare & call) · Parameters | `grep` beginner · pipes `\|` |
| 5 | Arrays · `for` loops | `cp` `mv` `rm` (safe mode) |
| 6 | Objects · dot notation | Permissions `ls -l` · `chmod` intro |
| 7 | **BOSS:** tiny script + file IO read | **BOSS:** navigate & find a file in 60s |

## Week 2 — Yellow Belt: "I control flow"

| Day | Programming | Linux |
|-----|-------------|-------|

| 9 | Array methods `map` `filter` | `find` · `which` |
| 10 | Modules `import` / `export` | Environment `echo $PATH` |
| 11 | JSON parse/stringify | `curl` GET · status codes |
| 12 | Errors try/catch | Redirects `>` `>>` `2>&1` |
| 13 | Readline / CLI args `process.argv` | `nano` or `vim` survival 10 commands |
| 14 | **BOSS:** CLI quiz game | **BOSS:** pipeline extracts lines from log |
